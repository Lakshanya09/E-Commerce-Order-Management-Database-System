# Sales and Customer Analytics System

## Overview

This project implements SQL queries for analysing sales and customer data in an E-Commerce Database. It is used to generate reports related to sales, customer purchases, best-selling products, and category-wise sales.

## Tables Used

- `customers`
- `products`
- `categories`
- `orders`
- `order_details`
- `payment`

## Reports Generated

- Sales Analysis Report
- Customer Purchase Analysis Report
- Best-Selling Product Report
- Category-Wise Sales Report

## SQL Concepts Used

- **SELECT** – Retrieves the required sales and customer data.
- **JOIN** – Combines data from related tables.
- **SUM** – Calculates total sales, quantity, and revenue.
- **COUNT** – Counts orders and customer purchases.
- **AVG** – Calculates the average order value.
- **GROUP BY** – Groups data by customers, products, and categories.
- **ORDER BY** – Sorts the results based on sales or quantity.
- **MAX / MIN** – Finds the highest and lowest values.
