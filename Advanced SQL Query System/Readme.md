# Week 10 – Advanced SQL Query System

## About the Project

This project focuses on **Advanced SQL Queries using Subqueries and Nested Queries** in an e-commerce database.

The SQL queries are used to analyze products, customers, sales performance, and business decisions.

## Reports

### Report 1 – Premium Product Report

Identifies products whose price is higher than the average product price and displays their category and stock availability.

## SQL Concepts Used

- Single-row subqueries
- Multi-row subqueries
- Nested subqueries
- Derived tables
- Aggregate functions
- `GROUP BY` and `HAVING`
- `JOIN`
- `UNION ALL`
- Conditional `CASE` statements
- Business-oriented data analysis

## Tools Used

- MySQL
- SQL
- GitHub

## Conclusion

The project demonstrates how advanced SQL subqueries and nested queries can be used to analyze an e-commerce database and generate useful insights for product, customer, sales, and business decision-making.
